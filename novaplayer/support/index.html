FAQ (English)

Nothing appears after adding a source

Open Settings → Sources & Network → Sources and run Scan All Sources. Confirm that the device may access the local network and that the server is reachable.

How should I enter a media server?

Choose Emby, Plex or Jellyfin as separate entries. Enter the protocol, host or IP, port and optional path separately. Emby and Jellyfin commonly use HTTP port 8096; Plex commonly uses port 32400 and requires a token.

What does Test do?

Test checks the current form without saving it. It validates the address, credential and protocol by reading the first directory page. A failed test shows a user-facing explanation and a stable error code.

Authentication failed

Check the username, password or token and the selected server type. Plex accepts a server access token; Jellyfin and Emby normally use username and password.

Why does metadata or artwork not load?

NovaPlayer uses TMDB for metadata and artwork. Check the network connection and the TMDB API key in Settings → Library & Metadata. Key tests use the current draft without saving it first.

How does iCloud sync work?

Sync is optional and requires Pro. Supported progress, favorites and settings go to your private iCloud database. Media files remain on their original source and credentials stay in Apple Keychain.

Restore a purchase

Open Settings → Subscription and use Restore Purchases while signed in with the same Apple Account.

Privacy and deletion

See the privacy policy. Delete sources in the app before uninstalling if you want their Keychain credentials removed.

常见问题（简体中文）

添加来源后没有内容

进入「设置 → 来源与网络 → 来源」，点击「扫描全部来源」。同时确认已允许本地网络访问，且服务器可以连接。

媒体服务器怎么填写？

Emby、Plex、Jellyfin 是三个独立入口。协议、地址、端口和可选路径分开填写。Emby / Jellyfin 常用 HTTP 8096；Plex 常用 32400，并要求填写令牌。

“测试”按钮会做什么？

测试只使用当前表单，不会保存来源。它会读取来源首页，验证地址、凭据和协议；失败时会显示用户化原因与稳定错误码。

认证失败

请核对用户名、密码或令牌，并确认服务器类型选择正确。Plex 使用服务器访问令牌；Jellyfin / Emby 通常使用用户名与密码。

元数据或海报没有加载

NovaPlayer 使用 TMDB 获取元数据与海报。请检查网络，以及「设置 → 媒体库与元数据」中的 TMDB Key。Key 测试会直接测试当前草稿，不要求先保存。

iCloud 同步怎么工作？

同步为 Pro 可选功能。受支持的进度、收藏与设置进入你的 iCloud 私有数据库；媒体文件仍保留在原来源，凭据仍保存在 Apple 钥匙串。

恢复购买

使用同一个 Apple 账号登录后，在「设置 → 订阅」中点击恢复购买。

隐私与删除

请阅读隐私政策。如需清除来源凭据，请先在应用内删除来源，再卸载应用。
